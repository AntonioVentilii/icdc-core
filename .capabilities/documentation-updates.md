# Capability: Documentation Updates

## Allowed

- Update `README.md` and `AGENTS.md` to reflect architectural changes.
- Maintain and update `.agents/` and `.claude/` configuration files.
- Create and update implementation plans and walkthroughs.
- Clarify domain logic or implementation patterns in `.agents/`.

## Forbidden

- Delete large sections of documentation without replacement.
- Modify governance files in `.policies/` or `.boundaries/` without explicit instruction.
