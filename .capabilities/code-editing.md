# Capability: Code Editing

## Allowed

- Modify existing functions and types in `src/`.
- Add new modules and files adhering to existing patterns.
- Refactor small to medium modules for clarity.
- Implement tests for new and existing code.

## Forbidden

- Modify CI/CD pipelines in `.github/workflows/` without explicit permission.
- Introduce new frameworks or large-scale architectural paradigm shifts.
- Change project-wide configurations (e.g., `dfx.json`, `package.json`) without approval.
