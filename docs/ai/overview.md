# AI System Overview

This document provides a high-level entry point for understanding the AI ecosystem within the `icdc-core` repository.

## Purpose

The AI layer is designed to make automation predictable, safe, and collaborative. By using a structured system of agents, governance, and workflows, we ensure that AI-driven changes adhere to our architectural standards and economic safety requirements.

## Key Components

### [Governance](file:///Users/antonio.ventilii/projects/icdc-core/docs/ai/governance.md)

The legal and regulatory framework that constrains agent behavior.

- **Policies**: Mandatory repository laws.
- **Capabilities**: Explicitly permitted actions.
- **Boundaries**: Protected and restricted areas.

### [Agent Ecosystem](file:///Users/antonio.ventilii/projects/icdc-core/docs/ai/agents.md)

The specialized roles that handle specific aspects of the development lifecycle.

- **Planner**: Architecture and task decomposition.
- **Implementer**: Code modification and technical compliance.
- **Reviewer**: Quality assurance and safety verification.

### [Workflows](file:///Users/antonio.ventilii/projects/icdc-core/docs/ai/workflows.md)

The coordinated processes and handoff patterns agents follow to achieve complex goals.

## How to Interact

Humans and AI tools interact using standardized configurations:

- **AGENTS.md**: The registry of all automated participants.
- **CLAUDE.md**: Model-specific optimization and behavior guides.
- **Implementation Plans**: Mandatory technical designs for non-trivial changes.
