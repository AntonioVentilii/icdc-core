# AI Glossary

Terminology used across the AI governance and agent system in the `icdc-core` repository.

### Agent

An automated or semi-automated AI system (e.g., Claude, Copilot) that performs tasks within the repository.

### Boundary

A protected zone or sensitive subsystem (defined in `.boundaries/`) where automated changes are restricted or require high scrutiny.

### Capability

An explicit permission or restriction (defined in `.capabilities/`) that describes what an agent is allowed to do.

### Governance Layer

The multi-layered system of documentation and rules that ensures AI agents operate safely and predictably.

### Implementation Plan

A mandatory artifact (`implementation_plan.md`) describing the technical design and verification steps for a proposed change.

### Orchestration

The coordination of multiple agents and tools to achieve a complex goal.

### Policy

A mandatory rule or repository law (defined in `.policies/`) that agents must follow.

### Task Boundary

A mechanism used to communicate the start, progress, and status of a specific technical task to the user.

### Walkthrough

An artifact (`walkthrough.md`) generated after task completion to summarize changes and verification results.

### Workflow

A series of coordinated steps and coordination patterns (defined in `.workflows/`) used by agents to solve specific types of problems.
